## 三、交通方式与费用

| 路段 | 方式 | 时长 / 费用 |
| --- | --- | --- |
| FCO → 罗马市区 | Leonardo Express | 约 32 分钟，€14/人 ×2 = €28 |
| 罗马 → 那不勒斯 | Frecciarossa/Italo 高铁 | 约 1h10，€20/人 ×2 = €40 |
| 那不勒斯 → 庞贝 | Circumvesuviana 城际 | 约 30 分钟，€3/人 ×2 往返 = €12 |
| 那不勒斯 → 罗马 | 高铁（返程） | 约 1h10，€20/人 ×2 = €40 |
| 罗马 → FCO | Leonardo Express | €14/人 ×2 = €28 |
| 市内交通 | 地铁/公交日票 | 罗马+那不勒斯约 €60（2 人） |
| 卡布里备选 | Molo Beverello 快船 | 约 45 分钟，€25/人 ×2 往返 = €100（可选） |

交通小计约 €208（不含卡布里备选）。高铁提前购「超级经济」价最低；罗马地铁日票 €7 划算。

## 七、提前预约 / 提前购票

下列项目建议提前在官网锁定，官网链接已附在对应条目后（PDF 中可点击）：

- 罗马斗兽场门票：官网 [ticketing.colosseo.it](https://ticketing.colosseo.it) 放票紧俏，提前 30 天关注预约（标准 €18 / 全套 €24）。
- 梵蒂冈博物馆：官网 [museivaticani.va](https://www.museivaticani.va) 提前订票免排队；圣彼得大教堂免费入，登穹顶约 €8–10 现场购。
- 庞贝古城：官网 [pompeiisites.org](https://pompeiisites.org) 提前购 Express €18（记名票，带护照）；旺季分上下午时段。
- 罗马↔那不勒斯高铁：[Trenitalia](https://www.trenitalia.com) / [Italo](https://www.italotreno.it) 提前购超级经济价。
- 卡布里岛快船：运营商 [snav.it](https://www.snav.it) 等官网购，旺季早班船易满，注意末班船时间。

## 八、实用贴士

- 斗兽场票含罗马广场与帕拉蒂尼山、24h 内有效，可错峰游览。
- 斗兽场票务必提前抢，否则现场排 2–3 小时且时段易售罄；记名票带护照、名字一致。
- 梵蒂冈博物馆周三/周日人流大，选早场或傍晚场人少；圣彼得大教堂安检排队，早上人少。
- 罗马地铁 A/B 线 + 公交日票 €7 划算；那不勒斯地铁 Line 1/2 覆盖主要点。
- 那不勒斯老城扒手较多，贵重物品随身；Termini、西班牙区、Chiaia/Lungomare 相对安全。
- Pizza 现烤趁热吃，那不勒斯中午开炉午餐最新鲜；餐厅 coperto 餐位费正常，小费非强制。
- 夏季防晒补水，庞贝遗址遮阴少，带帽与水；记名门票带护照原件核对。
- 备少量现金，多数店可刷卡；意大利用 Type C/F 欧标插头、230V，紧急电话 112。
- 购物单店满 €70 可离境退税；周日部分商店/餐厅休息，提前确认营业时间。
