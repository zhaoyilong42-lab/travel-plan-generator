## 七、提前预约 / 提前购票

下列项目建议提前在官网锁定，官网链接已附在对应条目后（PDF 中可点击）：

- 意铁高铁票：[Trenitalia](https://www.trenitalia.com) / [Italo](https://www.italotreno.it) 提前 2–4 周购「超级经济」价最低。

## 八、实用贴士

- 跨城多：行李从简，每站用车站寄存（Luggage Storage），轻装游玩。
- 意铁票分车次与车厢，上车前看清站台（Binario）与车厢号，避免上错车。
- 乌菲兹 / 学院美术馆为严格时段票，按预约时间到场，迟到可能不让进。
- 大教堂登顶电梯票为分时票，建议约在光线好的下午场次，登顶拍照最佳。
- 地铁/公交票记得进站打卡，逃票罚款高；威尼斯靠 Vaporetto，买 24h 票划算。
- 威尼斯多桥少坡道，带轮行李箱不便，建议用软包；穿舒适步行鞋。
- 餐厅多收 coperto（餐位费）属正常；小费非强制，凑整即可。
- 备少量现金（餐厅/厕所/小摊），多数店可刷卡；意大利用 Type C/F 欧标插头、230V。
- 带护照原件，Centrale、Duomo、圣马可广场人多防扒手；紧急电话 112。
- 街头饮水喷泉（nasoni）可接直饮水；购物单店满 €70 可离境退税。
